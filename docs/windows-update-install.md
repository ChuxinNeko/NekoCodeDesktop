# Windows 更新安装反馈

用户点击“重启并安装”后，应用先发布 `installing` 状态，说明主窗口即将关闭、安装进度会在独立窗口显示。Windows 使用非静默 NSIS 安装，安装进度窗口由安装器自身提供，可在 Electron 退出后继续显示。

`resources/installer.nsh` 仅调整带 `--updated` 的更新流程：

- 继承现有安装范围和路径，跳过用户范围、目录和完成确认页面。
- 不对更新路径执行首次安装的产品子目录补全，保留自定义目录。
- 显示安装进度和更新完成后自动重新打开的提示，安装结束后自动关闭进度窗口并启动应用。
- 兼容旧客户端的 `/S --updated --force-run`：仅显式重启安装切换为可见模式；普通退出触发的后台安装仍保持静默。

首次安装保留正常向导；Linux 保持原有安装行为。重复点击不重复启动安装，调用失败会保留已下载状态以便重试。

验证包括安装服务的状态/参数测试、渲染层状态提示测试，以及使用真实 electron-builder NSIS 模板编译隔离的空应用测试包。测试包仅用于验证编译，不安装真实应用。

正式发布前仍需在已安装旧版本的 Windows 虚拟机中覆盖：默认每用户安装、自定义名称的安装目录、管理员安装与 UAC、旧客户端发起更新、安装失败，以及安装完成后自动重新打开。
